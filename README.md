# LinkedIn-Assistant

This directory contains the scripts and workflows used to preprocess raw job and candidate datasets into clean, structured, and linkable representations for downstream modeling and knowledge-graph construction.

## Overview

The preprocessing pipeline prepares data by selecting the jobs from the domain of sales and technology for our knowledge graph and enriching the dataset with posting dates. For the resumes, we enriched the dataset with candidate names and email IDs

##  Running the Pipeline

```bash
python augment_data.py 
```
